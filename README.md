Документация системы менеджмента информационной безопасности

Назначение репозитория

Репозиторий предназначен для централизованного ведения документированной информации системы менеджмента информационной безопасности (СМИБ) с использованием системы контроля версий Git.

Репозиторий обеспечивает хранение документов, контроль изменений, идентификацию редакций, сохранение истории изменений и возможность восстановления предыдущих редакций.

Структура документации

01-politika/ — политика информационной безопасности верхнего уровня;

02-chastnye-politiki/ — частные политики информационной безопасности;

03-procedury/ — процедуры и регламенты;

04-instrukcii/ — инструкции, шаблоны и чек-листы;

05-zapisi/ — шаблоны записей СМИБ.

Не допускаются сообщения вида первый коммит, изменения, test и другие неинформативные описания.
